\thispagestyle{empty}

Prove the following result: if `xs` is a permutation of `ys`, then
the sum of the elements of `xs` is equal to the sum of the elements
of `ys`.

You can import any module from the Agda library used in the
lectures. Feel free to define any auxiliary function that may be
useful for specifying and proving the main result.

You have **20 minutes** to complete the assignment. When the time is
over, send your `.agda` file by email to `luca.padovani@unicam.it`.
Be ready to explain any part of the code you write.
